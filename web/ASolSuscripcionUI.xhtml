Descripcion de datos de entrada
Esta página permite registrar información sobre las Solicitudes de Suscripción de nuevos usuarios o Suscriptores del Sistema Condominio 4.0. En el contexto de este sistema, un Suscriptor es cualquier persona o empresa que desee hacer uso de las ventajas y beneficios en el uso de nuestras herramientas automatizadas, para la gestión eficiente de Condominios. El registro de los datos de las Solicitudes, se realiza a traves de la acción: Registrar, para el ingreso de datos tales como nombre y apellido del solicitante, cédula o RIF, correo electrónico, teléfonos y la información relacionada con el depósito o transferencia efectuados.
En esta sección, se muestra una descripción de los datos de entrada de esta página, asi como también, los tipos de datos y rangos válidos en los casos en que aplique.
