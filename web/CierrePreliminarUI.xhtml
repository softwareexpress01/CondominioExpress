Procesar cierre preliminar

Periodo a cerrar :

Este proceso realiza una simulación de las tareas a ser ejecutadas por el cierre definitivo:
1. Genera las alícuotas para cada inmueble (CxC).
2. Genera las facturas de cuotas especiales.
3. Genera notas de débito por intereses de mora.
4. Genera pagos automáticos a las CxC de cada inmueble.
5. Genera informes de cierre de mes.

Nota: Este proceso proporciona una vista preliminar de lo que serían los resultados del cierre para su revisión.
No actualiza la base de datos del sistema. Se recomienda realizarlo tantas veces como sea necesario antes del cierre definitivo.
