Procesar cierre mensual

Periodo a cerrar :

Este proceso realiza las siguientes tareas:
1. Genera las alícuotas para cada inmueble (CxC).
2. Genera las facturas de cuotas especiales.
3. Genera notas de débito por intereses de mora.
4. Genera pagos automáticos a las CxC de cada inmueble.
5. Genera informes de cierre de mes
6. Actualización de la base de datos.
7. Realiza el cierre definitivo de la gestión.

Este proceso deberia ser ejecutado los primeros dias del mes siguiente al mes a cerrar.
