Descripción de datos de entrada
Esta página proporciona entrada al sistema de administración de condominios de Software Express, C.A. Para acceder a la aplicación, el usuario deberá ingresar su código de usuario y su contraseña. En el caso de usuarios con perfil Administrador, el código y la contraseña a utilizar, es la misma con que realizó el registro. Para los usuarios con perfil Operador, se les dará acceso con el codigo de usuario y contraseña con que fueron registrados por el administrador, mediante la opción del menú de Datos básicos/Configuración/Perfiles. Para ingresar al sistema, se deben introducir los datos solicitados y hacer click sobre el botón Ingresar.
En esta sección, se muestra una descripción de los datos de entrada de esta página, así como también, los tipos de datos y rangos válidos en los casos en que aplique.
