Descripción de datos de entrada
Esta página permite, como parte del proceso de configuración del sistema, registrar y actualizar el Logo del condominio. Este logo, es una imagen que identifica a cada condominio. El usuario administrador puede seleccionar de sus archivos locales, cualquier imagen que quiera usar como logo. Existen, sin embargo, limitaciones en cuanto al tamaño del archivo y el de su nombre, como se vera mas adelante, en la descripcion de los elementos de la página. Para configurar el logo del sistema o para actualizarlo, se debe hacer click sobre el boton Seleccionar un archivo, el sistema, seguidamente, abrira una ventana estándar de selección de archivos. Seleccione el archivo a utilizar. Esta acción, hara que el sistema vuelva a la página anterior, pero mostrando esta vez el nombre del archivo seleccionado. Para terminar con el registro/actualización del logo, debe hacerse click sobre el botón Registrar.
En esta sección, solo se cubren las limitaciones en cuanto al tamaño del archivo a descargar, así como también, en cuanto al tamaño del nombre de archivo. Deberan seleccionarse imagenes que no excedan los parametros establecidos.
